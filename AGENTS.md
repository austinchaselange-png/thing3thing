# AGENTS.md — Things 3 client (thing3thing) audit rules

A Windows task manager built with Tauri 2 (Rust backend) + React/TypeScript UI.
It signs in to Things Cloud through a reverse-engineered protocol, stores the user's
credentials, and can WRITE to their real Things data after opt-in.

## Mode
READ-ONLY AUDIT. Do not edit, create, rename or delete any file except the report below.
Do not run cargo/npm installs or builds, the app, or the CLI. Never contact Things Cloud.
Do not browse the web.

## Scope — read ONLY these paths
- src-tauri/src/*.rs              ← entry point: main.rs → lib.rs
- src-tauri/tauri.conf.json
- src-tauri/capabilities/*.json
- src-tauri/Cargo.toml, Cargo.toml (root), crates/*/Cargo.toml  ← deps + release profile only
- crates/things-cloud/src/*.rs    (plus src/bin/things-cloud-cli.rs only if called out)
- crates/things-sync/src/*.rs
- src/main.tsx, src/quick-entry.tsx, src/App.tsx, src/store.ts, src/actions.ts, src/types.ts
- src/backend/Backend.ts, src/backend/index.ts, src/backend/tauri.ts
- src/components/*.tsx
- src/lib/*.ts (excluding *.test.ts)
- package.json, vite.config.ts   ← deps + build config only

## Never read
node_modules/, target/, dist/, .git/, docs/, src-tauri/permissions/autogenerated/,
src-tauri/icons/, src/styles/fonts/, *.test.ts, *.test.tsx, src/test-setup.ts,
src/backend/mock.ts, src/backend/mockData.ts, crates/things-cloud/src/fake.rs,
crates/things-sync/src/demo.rs, lock files.
Do NOT look at the separate `cairn` repo — it is an older copy of this app.

## Stay on task
- No refactors, no style/naming/formatting comments, no "while I'm here" work.
- If something outside scope looks relevant, add ONE line under
  "Out of scope — flagged" in the report. Do not go read it.
- Only report issues you can point to by file:line. No generic best-practice filler.

## Output
Write the report to `audits/things3.md`. Nothing else.
